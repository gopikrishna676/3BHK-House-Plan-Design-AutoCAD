# Residential Building Planning and Structural Layout Design

## Overview
This project focuses on the planning and structural layout design of a residential building using engineering drafting and structural planning concepts. The project includes architectural layouts along with structural detailing required for residential construction.

The complete design package was prepared with proper dimensional planning, room allocation, structural member placement, and construction-oriented drafting practices.

---

## Project Scope
The project covers:
- Residential floor planning
- Room dimension planning
- Furniture layout
- Door and window scheduling
- Column layout design
- Footing layout planning
- Roof beam layout preparation

---

## Design Features

### Architectural Planning
The residential plan includes:
- Living Room
- Master Bedroom
- Guest Bedroom
- Kitchen
- Dining Area
- Pooja Room
- Washrooms
- Store Room
- Sit-out Area
- Internal Passages

The layout was designed for efficient space utilization and comfortable movement between rooms.

### Structural Layout Design
Structural components were planned to ensure:
- Proper load distribution
- Structural stability
- Organized column alignment
- Foundation support through footing layouts
- Roof beam connectivity

### Opening and Dimension Planning
Detailed opening schedules for:
- Doors
- Windows
- Ventilators

were included along with their dimensions and placement specifications.
